## 🎮 About the Game

Combolands: Roguelike Citybuilder is a single-player indie strategy game developed and published by Crux Games. It released for Windows on August 24, 2026. The game combines city building, deckbuilding, turn-based strategy, and roguelike progression.

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Combolands: Roguelike Citybuilder**. This trainer enhances Combolands runs by managing city resources, rerolls, guild progression, and building selection. It is designed around the game's short, turn-based citybuilding sessions, where players place buildings, create synergies, trigger cascading combos, and combine two guilds with distinct strengths and drawbacks.

**Target Audience:** Players who want to experiment with city layouts, test guild combinations, explore building synergies, accelerate unlock progression, or make short roguelike runs more forgiving.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Combolands is a stationary, grid-based citybuilder rather than a character-controlled exploration game. Use the mouse or controller to select building options and place structures on the available terrain. Movement-related trainer options are not applicable.

### Tools & Inventory

Buildings function as the primary selectable pieces in each run, with cards and building choices shaping the available strategy. The trainer focuses on building selection, rerolls, resources, and guild progression instead of a traditional character inventory.

### World & Environment

Each run centers on developing a small procedural city by placing buildings, combining neighboring effects, and creating powerful synergies. Choose two guilds per run, account for their unique strengths and drawbacks, and use the trainer to test layouts or maintain selected run values.

### Combat & Weapons

Combolands does not use conventional real-time or turn-based combat. Progress is driven by city planning, resource management, guild combinations, building placement, and cascading score or effect combos. Combat-related trainer options are therefore not included.
